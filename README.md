# La spesa del sabato — Ale + Lisa

Web-app personale: genera la lista della spesa settimanale combinata a partire dai nostri
piani alimentari, divisa fra Lidl e REWE, per la spesa del sabato a Hamburg-Nord.

Un solo file HTML self-contained (`index.html`) + icone, manifest e service worker per
l'uso offline come app da schermata Home su iPhone.
